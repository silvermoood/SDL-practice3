# Задание №3 — Университетская база данных

В работе разработано консольное Python-приложение для работы с PostgreSQL
В качестве предметной области выбрана университетская база данных

## Структура базы данных

В базе используются 5 связанных таблиц:

- `groups` — учебные группы
- `students` — студенты
- `teachers` — преподаватели
- `subjects` — учебные предметы
- `enrollments` — связь студентов с предметами и оценки

Связи между таблицами реализованы с помощью внешних ключей

## Возможности приложения

Программа позволяет:

- просматривать все записи таблицы
- выполнять поиск по одной колонке
- выполнять поиск по нескольким условиям
- изменять одну запись
- изменять несколько записей одновременно
- добавлять одну запись
- добавлять несколько записей
- добавлять студента вместе с его предметами и оценками
- работать с несколькими связанными таблицами
- получать ID добавленной записи

Также предусмотрено логирование успешных и ошибочных операций
